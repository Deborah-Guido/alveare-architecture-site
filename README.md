# Site Alveare Architecture

Site statique de l'agence (HTML/CSS, sans dépendance), déployé sur l'hébergement OVHcloud via l'intégration Git (Mes sites › Associer Git, branche `main`).

- `index.html`, `patrimoine.html`, `moex.html`, `environnement.html`, `journal.html`, `contact.html`, `mentions-legales.html`, `404.html`
- `style.css`, `assets/img/`, `assets/favicon.svg`
- `.htaccess` : HTTPS, redirections 301 des anciennes adresses Wix, page 404
- `robots.txt`, `sitemap.xml`
- `LISEZ-MOI.md` : guide de mise en ligne et DNS
